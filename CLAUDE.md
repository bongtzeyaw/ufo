# What this project is

PURSUE UAP Map — an unofficial static site that plots the declassified UAP
videos and images from https://www.war.gov/UFO/ (the U.S. DoW "PURSUE"
program) on an interactive Leaflet map. Live at https://ufo.bongtzeyaw.com,
deployed by GitHub Pages from `.github/workflows/pages.yml` on push to main.

## Architecture (3 stages, no backend)

```
data/uap-data.csv      raw snapshot of war.gov's own CSV (all 334 records, 4 releases)
etl/gazetteer.json     hand-curated: location string -> lat/lng + radius_km (+ kind
                       only for offworld/unmappable entries)
etl/build.py           joins the two -> site/data/records.json (videos+images only)
site/                  plain HTML/CSS/JS, Leaflet vendored in site/vendor/leaflet/
```

Key facts that took real effort to learn — do not re-derive:

- war.gov 403s non-browser HTTP clients (curl, requests). The CSV must be
  fetched from a real browser context; `scripts/fetch_data.py` (Playwright)
  does this. The site's `?release=N` param is a cache-buster, NOT a filter —
  every value returns the identical file containing all releases.
- Videos are NOT hosted here: they stream from DVIDS
  (`dvidshub.net/video/embed/<id>`). Images hotlink from war.gov (its bot
  protection does not block `<img>` requests from pages).
- `site/data/records.json` is generated by `etl/build.py` but checked in on
  purpose (deploy = static copy, no build step in CI).
- `etl/build.py` deliberately keeps only VID+IMG records (130 of 334; audio
  and PDFs are out of scope) and exits non-zero if the CSV contains a
  location string missing from the gazetteer (new releases add vocabulary).
- Locations are coarse official text ("CENTCOM", "Western United States");
  the gazetteer radius is drawn as a dashed, lightly shaded circle (hover =
  preview, click = pinned while the panel is open). All bubbles are one blue;
  precision-kind classification was removed deliberately.
- Off-world records (Moon/orbit) and no-location records are reachable via
  shelf buttons, never map bubbles. Frontend counts: 130 records = 110
  mappable (27 bubbles) + 9 off-world + 11 no-location.
- The visual design system (light/dark theme tokens, theming mechanism, brand
  assets) is documented in DESIGN.md; `site/css/style.css` is canonical for
  token values.

## Commands

```sh
python3 -m http.server 8642 --directory site   # local preview
python3 scripts/fetch_data.py                  # refresh CSV (needs playwright+firefox)
python3 etl/build.py                           # regenerate records.json
```

Data refresh flow: fetch -> build (fix gazetteer if it fails) -> commit both
`data/uap-data.csv` and `site/data/records.json` together.
